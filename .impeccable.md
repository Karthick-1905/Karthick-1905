## Design Context

### Users
GitHub visitors, collaborators, recruiters, and fellow developers who want a quick, friendly read on Karthick JS's interests, tools, and ways to connect.

### Brand Personality
Curious, playful, builder-minded. The profile should feel capable without being stiff, and personal without becoming noisy.

### Aesthetic Direction
A warm, editorial developer profile with a small amount of playful internet culture. Use clear sections, restrained HTML, familiar GitHub-native iconography, and the Blip cat as the distinctive visual signature. Keep it readable in both GitHub themes.

### Design Principles
- Lead with a clear point of view instead of a generic skill list.
- Use visual rhythm and short sections so visitors can scan quickly.
- Let the existing technology icons and contribution snake remain useful anchors.
- Add personality through concise copy and one memorable interactive detail.
- Prefer accessible labels, reliable image URLs, and graceful fallbacks.
